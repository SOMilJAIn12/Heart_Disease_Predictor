# Heart Disease Prediction 

## Problem Statement
Heart disease is one of the leading causes of death worldwide.  
The objective of this project is to predict whether a person is likely to have heart disease based on medical attributes using machine learning.



## Dataset
- Structured medical dataset
- Contains features such as age, cholesterol, blood pressure, heart rate, etc.
- Binary classification problem (Heart Disease: Yes / No)
- Source: Public UCI / Kaggle Heart Disease Dataset



## Approach
- Exploratory Data Analysis (EDA)
- Data Cleaning & Preprocessing
- Feature Scaling
- Model Training
- Hyperparameter Tuning
- Model Evaluation



## Models Used
- Logistic Regression
- Hyperparameter Tuning using GridSearchCV / RandomizedSearchCV
- Comparison based on evaluation metrics



## Evaluation Metrics
The following metrics were used to evaluate the model:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC Curve



## Results
- The model predicts heart disease with high accuracy
- Balanced evaluation using precision and recall
- ROC-AUC used to measure overall model performance



## Tech Stack
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn



## Key Learnings
- End-to-end classification pipeline
- Importance of feature preprocessing in medical data
- Model evaluation using multiple metrics
- Hyperparameter tuning for better generalization
